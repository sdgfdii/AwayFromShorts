统计你点「✅ 临时解除」的次数与时长：从解除开始计，到恢复屏蔽 / 被清除 / 强制压过时结算。强制模式下无法解除、关闭总开关或修改计划均不计入；数据只存本机，不同步云端。

🔐 登录 GitHub 账号

输入 GitHub Personal Access Token(勾选 gist 权限),配置将通过私有 Gist 在多台设备间同步。Token 用系统加密(DPAPI)只保存在本机,仅发送到 api.github.com。
如何创建 Token(点击展开)
  1. 打开 github.com/settings/tokens
  2. 点 Generate new token → Generate new token (classic)
  3. 勾选 gist 权限
  4. 生成后复制 ghp_... 开头的字符串,粘贴到上面输入框

工作原理(点击展开)
  • 网站屏蔽: 屏蔽期间向 hosts 文件写入 0.0.0.0 域名 记录,浏览器无法解析这些域名;解除时自动清除,只删除本程序写入的行,不动你的其他配置。
  • 进程屏蔽: 强制结束匹配的进程,每分钟复查一次。
  • 计划任务: 安装时注册 "AwayFromShorts" 任务,每分钟运行一次屏蔽引擎(需要管理员权限写 hosts)。
  • 本配置面板只是本地网页(127.0.0.1),不会联网发送任何数据。

🗑 卸载

卸载会删除计划任务、恢复 hosts 文件(仅移除本程序写入的行)、删除程序目录。你的其他文件不受影响。
也可以手动运行 %LOCALAPPDATA%\AwayFromShorts\uninstall.bat(需管理员)。
